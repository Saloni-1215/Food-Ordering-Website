# 🍔 Food Ordering Website UI

## 📌 About
This project is a food ordering web interface built using HTML and CSS.  
It simulates a modern food delivery platform where users can browse menu items and interact with a clean UI.

---

## 🎯 Features
- Menu item cards (Pizza, Burger, Drinks, etc.)
- Clean and user-friendly UI  
- Interactive "Add" buttons (UI level)  
- Responsive layout using Flexbox  
- Structured design similar to real food apps  

---

## 🛠 Tech Stack
- HTML5  
- CSS3  

---

## 📸 Preview
A simple food ordering interface displaying menu items with pricing and action buttons.
